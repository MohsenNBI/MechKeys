# MechKeys — صدای کیبورد مکانیکی روی ویندوز

برنامهٔ کوچکی برای ویندوز که هر کلیدِ صفحه‌کلید را به صدای یک سوئیچِ مکانیکی
واقعی تبدیل می‌کند: قلاب سراسریِ کیبورد، صدای ضبط‌شده روی بردِ واقعی، و خروجی
WASAPI با تأخیرِ چند میلی‌ثانیه. نوشته شده با Rust و Tauri ۲.

![نمای برنامه](docs/screenshot.png)

همین پنجره با زبانِ فارسی؛ پیش‌فرضِ برنامه انگلیسی است. دکمهٔ «English / فارسی»
پایینِ پنجره همه‌چیز را یک‌جا عوض می‌کند: متنِ خودِ پنجره، جهتِ چپ‌به‌راست و
راست‌به‌چپ، فهرستِ سینیِ سیستم و عنوانِ نوارِ بالا.

![نمای فارسی](docs/screenshot-fa.png)

صفحه‌کلید شما صدای «خودش» را نمی‌گیرد؛ هر کلید بر اساس جای فیزیکی‌اش روی برد
صدای متفاوتی دارد — کلیدهای وسطِ صفحه شل‌تر و بم‌تر، کلیدهای نزدیکِ قاب محکم‌تر
و تیزتر، و هر کلید در فشارهای پشتِ سرِهم نمونه‌های متفاوتی از همان سوئیچ را
پخش می‌کند تا صدا تکراری به نظر نرسد.

## ویژگی‌ها

- **۱۲ سوئیچِ واقعی**: MX Blue، MX Brown، MX Black، Holy Panda، Topre، NK Cream،
  Alpaca، Ink Black، Ink Red، Box Navy، Alps Blue، Model M.
- **۵ ساز برای حالت CUSTOM**: پیانو، پیانوی برقی، ماریمبا، زنگوله و گیتار. در این
  حالت به‌جای صدای سوئیچ، کلیدهای صفحه‌کلید نُت می‌نوازند.
- **صدای هر کلید جدا از کلید کناری‌اش** — بر پایهٔ جای کلید روی برد، نه یک فایلِ
  تکراری روی همهٔ کلیدها.
- **تأخیرِ کم**: حالت انحصاریِ WASAPI با دورهٔ ۳٫۳۳ میلی‌ثانیه؛ در عمل معمولاً
  بین ۱ تا ۲ میلی‌ثانیه از فشارِ کلید تا شروعِ صدا.
- **آزادسازی خودکارِ حالت انحصاری**: وقتی فیلمی پخش می‌شود، MechKeys خودش از
  انحصار بیرون می‌آید و با نخستین تایپ برمی‌گردد.
- **بدون نصبِ سنگین، بدون اجرا در پس‌زمینهٔ پرهزینه**: یک فایل اجرایی ~۹ مگابایت،
  پنجرهٔ ۴۰۰×۶۸۴ پیکسل با سه تب، و در حالت بیکار کمتر از ۰٫۱٪ پردازنده
  (اندازه‌گیری روی ۱۲ هسته، با پنجرهٔ باز).
- **به‌روزرسانی از گیت‌هاب**، با یک دکمه و اختیاری.
- **دوزبانه**: رابط در دو زبان فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست)، با
  کلیدِ عوض‌کردنِ زبان کنارِ دکمهٔ «پنهان کردن». پیش‌فرض انگلیسی است و انتخابت
  در فایلِ تنظیمات می‌ماند؛ فهرستِ سینیِ سیستم و عنوانِ پنجره هم به همان زبان
  نوشته می‌شوند.
- سینیِ سیستم، و اجرای خودکار با ویندوز.

## نصب

از صفحهٔ
[Releases](https://github.com/mohsenNBI/MechKeys/releases/latest)
فایل `MechKeys_x.y.z_x64-setup.exe` را بگیرید و اجرا کنید. برنامه در
`%LOCALAPPDATA%\Programs\MechKeys` نصب می‌شود و در سینیِ سیستم جای می‌گیرد.

اگر ویندوز هنگام اجرا پیام «SmartScreen» نشان داد (چون نصب‌کننده امضایِ پولیِ
ناشر ندارد)، روی **More info** و بعد **Run anyway** بزنید.

ویندوز ۱۰ و ۱۱، فقط ۶۴ بیتی.

| خودِ صفحه‌کلید | هر کی‌کپ با کلیک، همان کلید را با همان صدایی می‌نوازد که فیزیکی فشرده شود. |

| **آزادسازی خودکار** | هنگام پخشِ فیلم انحصار را موقتاً بیرون می‌دهد (پایین‌تر توضیح داده شده). |
| **صدای رها کردن کلید** | همان تقِ کوتاهِ برگشتِ کی‌کپ. |

خروج از برنامه در خودِ پنجره نیست: با راست‌کلیک روی نشانهٔ کنار ساعتِ ویندوز و
گزینهٔ **خروج / Quit**.

### صفحه‌کلیدِ روی پنجره

نیمِ بالای پنجره یک صفحه‌کلیدِ ۶۵ درصدی است، نه تزئین: ردیفِ عملکرد، ردیفِ عدد،
ردیف‌های حرف و گوشهٔ کلیدهای جهت‌نما، با همان نسبتِ عرضِ کلیدها روی بردِ واقعی
(۱٫۲۵u برای Ctrl، ۴٫۵u برای Space). هر کی‌کپ دو شمارهٔ خودش را می‌داند:
`vk` همان چیزی که قلابِ ویندوز گزارش می‌دهد و `scan` همان چیزی که موتورِ صدا
با آن مسیر می‌کند؛ برای همین کلیک روی یک کلید دقیقاً صدای همان کلید را
می‌دهد، نه صدای کلیدی دیگر را.

وقتی کلیدی را واقعاً فشرده می‌کنی، کی‌کپش پایین می‌رود، کهربایی می‌شود و یک
حلقه دورش باز می‌شود. پنجره که بسته باشد، ضربه‌ها در یک حلقهٔ ۶۴ تاییِ بدون
قفل می‌مانند و با بازکردنِ پنجره به همان ترتیب بازپخش می‌شوند — پس تایپی که
در حینِ پنهان بودنِ برنامه زده‌ای، بعداً روی برد دیده می‌شود.

برای کیبوردِ صفحه‌نمایشی هم همین راه می‌رود؛ و چون کلیدها روی برد نقشه دارند،
با Tab هم می‌توان روی صفحه‌کلید راه رفت (کلیدهای جهت‌نما) و با Enter آن کلید
را نواخت.

### چرا صدای هر کلید فرق دارد

برداشتِ صدا از ضبط‌هایِ خامِ سوئیچ انجام شده (دربارهٔ منبع و پروانه در بخشِ
پروانه). روی آن سه لایهٔ پردازش نشسته است:

1. **مسیرِ نمونه‌ها بر پایهٔ ردیفِ فیزیکی**: هر ردیفِ صفحه‌کلید take هایِ خودش را
   دارد، پس Space با Shift یکی صد نمی‌دهد.
2. **رزونانسِ بدنه**: یک فیلترِ عبورِ باند روی هر کلید، که بسامدِ مرکزی‌اش با
   فاصله از مرکزِ برد جابه‌جا می‌شود. کلیدهای کنارِ قاب «تق»ِ فلزیِ بیشتری دارند.
3. **تنوعِ ضربه**: هر فشار با نمونه‌ای دیگر از همان ردیف و با بلندیِ کمی متفاوت
   پخش می‌شود؛ نگه‌داشتنِ کلید هم صدایِ ممتد تولید نمی‌کند، چون رویدادِ تکرارِ
   ویندوز نادیده گرفته می‌شود.

حداکثر ۲۴ صدا هم‌زمان پخش می‌شود، پس تایپِ سریع هم هیچ کلیدی را جا نمی‌اندازد.

### حالت CUSTOM و سازها

در این حالت بانکِ صدا عوض می‌شود: هر کلید یک نُت از پلهٔ دو می‌نوازد و چیدمان
نُت‌ها از چپ به راستِ صفحه‌کلید است (کلیدهای یک ردیف، نُت‌های یک اکتاو). صداها
ضبط‌شده نیستند؛ با مدلِ مَدال (خاموش‌شدنِ تک‌تکِ هارمونیک‌ها) ساخته می‌شوند، پس
هیچ فایلِ صوتیِ اضافه‌ای به برنامه اضافه نمی‌شود. فقط سازی که انتخاب کرده‌اید
ساخته می‌شود و ساختنش روی رشته‌ای جدا از رشتهٔ صدا انجام می‌گیرد، بنابراین
تعویضِ ساز، تایپِ وسطِ فیلم را نمی‌شکند.

## تأخیر

دو مسیرِ خروجی وجود دارد:

| مسیر | دورهٔ بافر | تأخیرِ اندازه‌گیری‌شده |
| --- | --- | --- |
| اشتراکی (پیش‌فرض) | ۴۸۰ فریم = ۱۰٫۰۰ ms | میانه ۵٫۴ تا ۶٫۶ ms (`--selftest`) |
| انحصاری | ۱۶۰ فریم = ۳٫۳۳ ms (کمینهٔ دستگاه) | میانه ۰٫۸ تا ۲٫۷ ms (`--selftest --exclusive`) |

عددِ بالا فاصلهٔ «فشارِ کلید تا نخستین نمونهٔ صوتیِ آماده» است و هر بار که
اجراش کنی عوض می‌شود؛ اینها چهار اندازه‌گیری پشتِ سرِ هم روی همین دستگاه‌اند.
خودِ برنامه همان را در بالای پنجره نشان می‌دهد. برای دیدنِ آنچه دستگاهِ شما
می‌پذیرد:

```
mechkeys --probe
```

حالت انحصاریِ WASAPI صفحهٔ صوتی را قفل می‌کند و هیچ برنامهٔ دیگری صدا نخواهد
داشت. برای همین «آزادسازی خودکار» هست.

### آزادسازی خودکارِ حالت انحصاری

با این تیک، نظارتگرِ برنامه این کارها را می‌کند:

- اگر ۱۲ ثانیه هیچ کلیدی فشرده نشود، انحصار بیرون داده می‌شود و خروجی به حالت
  اشتراکی می‌رود؛ حالا می‌توانید فیلم ببینید.
- تا وقتی صدایِ قابلِشنوی از برنامهٔ دیگری در حالِ پخش است، در همان حالت می‌ماند
  (برنامه‌ای که فقط یک استریمِ بی‌صدا باز نگه داشته، مانعِ بازگشت نمی‌شود).
- وقتی پخش تمام شد و دوباره شروع به تایپ کردید، انحصار خودش برمی‌گردد — معمولاً
  تا دو ثانیه.

وقتی انحصار موقتاً بیرون رفته باشد، برچسبِ «موقتاً آزاد شد» کنارِ همان گزینه
نشان داده می‌شود. برای فهمیدنِ اینکه چه برنامه‌ای صفحهٔ صوتی را نگه داشته:

```
mechkeys --sessions
```

## به‌روزرسانی

دکمهٔ **بررسی به‌روزرسانی** نشانیِ
`api.github.com/repos/mohsenNBI/MechKeys/releases/latest`
را می‌پرسد و اگر نسخهٔ تازه‌تری بود، شماره، یادداشت‌ها و پیوندِ صفحهٔ انتشار را
نشان می‌دهد. تیکِ **بررسی خودکار** یعنی همین پرس‌وجو یک بار هنگامِ اجرای برنامه
انجام شود (بی‌صدا؛ فقط اگر نسخهٔ تازه‌تری باشد چیزی در پنجره نوشته می‌شود).

**دریافت نصب‌کننده** فایل را به پوشهٔ Downloads می‌گیرد و تمام. برنامه هیچ‌وقت
چیزی که دانلود کرده را خودش اجرا نمی‌کند — باید خودتان دو بار رویاش کلیک کنید.
این تصمیمِ عمدی است: تا وقتی امضایِ دیجیتالِ پرداخت‌شده‌ای روی نصب‌کننده نباشد،
اجرای خودکارِ فایلِ دانلودیِ از شبکه، یک زنجیرهٔ تأمینِ نرم‌افزارِ شکننده است.

## حریم خصوصی

- هیچ داده‌ای دربارهٔ شما، کلیدهای فشرده‌شده، یا سیستم جمع‌آوری نمی‌شود.
- تنها درخواستِ شبکه‌ای که این برنامه می‌زند همان پرس‌وجویِ گیت‌هاب است؛ با
  خاموش‌کردنِ «بررسی خودکار» و نزدنِ دکمه، برنامه کاملاً آفلاین کار می‌کند.
- تنظیمات در `%APPDATA%\MechKeys\config.json` می‌نشیند و هیچ چیز دیگری روی دیسک
  نمی‌نویسد (نصب‌کنندهٔ دانلودشده اگر بخواهید، در Downloads).

## تنظیمات

```json
{
  "enabled": true,
  "volume": 0.7,
  "profile": "mx-blue",
  "up_sound": true,
  "exclusive": false,
  "auto_release": false,
  "check_updates": true,
  "lang": "en"
}
```

| کلید | معنا |
| --- | --- |
| `enabled` | روشن/خاموش بودنِ صدا. |
| `volume` | عددی بین ۰ و ۱. |
| `profile` | نامِ سوئیچ یا ساز؛ همان مقدارهای فهرستِ بالا، مثل `holy-panda` یا `piano`. |
| `up_sound` | صدای رها کردنِ کلید. |
| `exclusive` | حالت انحصاریِ WASAPI. |
| `auto_release` | آزادسازی خودکارِ انحصار. |
| `check_updates` | پرس‌وجوی گیت‌هاب هنگامِ اجرا. |
| `lang` | `en` یا `fa`. هر چیز دیگری به `en` برمی‌گردد. |

## خط فرمان

| پرچم | کار |
| --- | --- |
| *(بدون پرچم)* | اجرای معمولی با پنجره. |
| `--minimized` | شروع در سینی، بدون پنجره. |
| `--selftest` | آزمونِ بی‌سر و صدا: قلاب → صف → میکسر را با ۲۰ ضربهٔ ساختگی می‌سنجد و زمانِ رسیدنِ صدا را گزارش می‌دهد. |
| `--selftest --exclusive` | همان آزمون در حالت انحصاری. |
| `--probe` | دورهٔ کمینه، نرخِ نمونه و قالبِ پذیرفته‌شدهٔ دستگاهِ پیش‌فرض را چاپ می‌کند. |
| `--sessions` | فهرستِ استریم‌های صوتیِ روی دستگاهِ پیش‌فرض، با سطحِ صدا و اینکه کدام‌شان مانعِ حالت انحصاری است. |

## ساخت از منبع

پیش‌نیازها: Rust (stable)، Node ۱۸ یا تازه‌تر، و روی ویندوز Visual Studio Build
Tools با کامپوننتِ C++، چون `windows` و `webview2` به `link.exe` نیاز دارند.

```bash
cd src-tauri
cargo test --release          # ۴۹ آزمون
cargo build --release         # target/release/mechkeys.exe

npx --yes @tauri-apps/cli@2 build   # نصب‌کنندهٔ NSIS در
                                    # src-tauri/target/release/bundle/nsis
```

صداها بخشی از مخزن‌اند. اگر بخواهید از نو از منبعِ اصلی‌شان ساخته شوند:

```bash
node tools/build-sounds.mjs   # دانلودِ ضبط‌های kbsim، برش، نرمال‌سازی، ۴۸kHz
node tools/gen-icons.mjs      # icons/ و src/icon.png از tools/icon-master.png
```


هر پوشه با `cargo test --release` آزمون‌هایِ خودش را دارد؛ آزمون‌ها روی منطق
نشسته‌اند (مسیرِ کلیدها، قالب‌هایِ صدا، قواعدِ زمان‌بندیِ نظارتگر، تجزیهٔ پاسخِ
گیت‌هاب) و نیازی به دستگاهِ صوتی ندارند.

### گذاشتن روی گیت‌هاب

مخزن هیچ فایلِ ساخته‌شده‌ای ندارد (`target/`، `node_modules/` و `.cache/` در
`.gitignore` هستند)، پس پوشه را همان‌طور که هست می‌توان اولین کامیت زد:

```bash
git init -b main
git add .
git commit -m "MechKeys 1.5.0"
git remote add origin https://github.com/mohsenNBI/MechKeys.git
git push -u origin main
git tag v1.5.0 && git push origin v1.5.0
```

بیلدِ GitHub Actions با هر پوش تست‌ها را اجرا می‌کند و نصب‌کننده را می‌سازد؛
برچسبِ `v*` علاوه بر آن، نصب‌کننده را روی خودِ انتشار می‌گذارد — همان جایی که
دکمهٔ «بررسی به‌روزرسانی» در برنامه دنبالش می‌گردد.

## عیب‌یابی

| نشانه | کار |
| --- | --- |
| هیچ صدایی نمی‌آید | کلیدِ بالای پنجره را روشن کنید؛ بعد `پخش آزمایشی` را بزنید. اگر آن هم بی‌صدا بود، خروجیِ ویندوز را عوض کنید. |
| صدا با تأخیرِ محسوس می‌آید | **حالت انحصاری** را روشن کنید و `mechkeys --probe` را ببینید. |
| موقع پخشِ فیلم صدا ندارید | همین است: حالت انحصاری صفحهٔ صوتی را قفل کرده. خاموشش کنید یا **آزادسازی خودکار** را روشن کنید. |
| حالت انحصاری برنمی‌گردد | `mechkeys --sessions` را اجرا کنید؛ ستونِ «in the way» می‌گوید کدام برنامه صفحه را نگه داشته است. |
| برنامه‌هایِ اجراشده به‌عنوان مدیرِ سیستم صدا ندارند | قلابِ کیبورد نمی‌تواند ورودیِ آن‌ها را ببیند؛ MechKeys را هم به‌عنوان مدیر اجرا کنید. |
| SmartScreen جلوی نصب‌کننده را می‌گیرد | More info → Run anyway. |
| بررسیِ به‌روزرسانی خطا داد | دسترسی به `api.github.com` را بررسی کنید؛ اگر محدودیتِ نرخ خوردید، چند دقیقه بعد دوباره امتحان کنید. |
